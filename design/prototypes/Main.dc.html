Рынок мыслит книгами
Blinkist, Headway, Shortform продают пересказ одной книги. «Темы» у них — плейлисты из таких пересказов, а не единый курс.
Источник теряется
По главам разбирает только Shortform — и только одну книгу. Связи «мысль → книга → глава» внутри курса нет ни у кого.
Голос — пока эксперимент
Разговор с AI-ведущими есть в NotebookLM, но только по вашим файлам и только на английском. Готовой программы там нет.
Главный риск — BeFreed
Уже делает персональные AI-аудиоуроки из нескольких источников. Наше отличие: ссылки до главы, курс с результатом, работа в браузере.
